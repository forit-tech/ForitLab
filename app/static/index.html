Как это работает

Что такое Forit Lab

Forit Lab — лаборатория из шести небольших, но серьёзных инструментов для работы с данными, API и текстом. Каждый решает свой этап: найти источник → добыть → создать/испортить → исследовать → сравнить → проверить клиент. Всё работает без базы, очередей и нейросетей — на чистом Python.

Как устроен конвейер

Инструменты соединяются в цепочку. Типичный путь: API Finder находит источник → Web Harvester достаёт данные → Data Burner плодит синтетику с дефектами → Unicode Crime Lab вскрывает текстовый мусор → Drift Lab сравнивает версии → Chaos API проверяет, переживёт ли твой клиент реальную жизнь.

Web Parser · сбор данных с сайтов

Достань данные с сайта

Вставь ссылку, HTML, JSON или строку curl — Lab определит источник данных и поможет собрать их в таблицу. Субфаза 1a: определение источника. Извлечение полей, обход и экспорт — в следующих субфазах.

parser://input
Запрос идёт через защищённый сетевой слой · приватные адреса блокируются · JS не исполняется
01
Web Harvester · извлечение данных

Достань данные со страницы

Вставь ссылку — получишь таблицы, повторяющиеся сущности, метаданные и кандидатов в API. Любую часть можно выгрузить датасетом.

harvest://input
http/https · robots.txt соблюдается · приватные адреса блокируются · JS не исполняется
02
API Finder · поиск источников

Найди бесплатный API

Только то, чем можно пользоваться бесплатно: free forever, free tier, open data или без ключа. Trial-only не показываем.

apifinder://query
03
Data Burner · генератор данных

Создай синтетику с дефектами

Реалистичные выгрузки с управляемой грязью: пропуски, выбросы, дубли, перекос, unicode-ловушки, сломанные даты. Пара к Drift Lab.

burner://spec
04
Drift Lab · сравнение версий

Сравни две выгрузки

reference vs current: смена схемы, распределения (PSI, KS), категории, пропуски, утечка идентификаторов — с объяснением, а не «drift = 0.42».

drift://compare
Нет файлов под рукой? «Демо» прогонит встроенный датасет с подложенным дрейфом. Или собери пару в Data Burner.
05
Unicode Crime Lab · разбор текста

Раскопай текстовый трэш

Невидимые символы, zero-width, NBSP, NFC/NFD, кириллица под видом латиницы — с подсветкой прямо в тексте.

unicode://inspect
06
Chaos API · стресс клиента

Сломай свой клиент

Собери эндпоинт, который ведёт себя как мудак: задержки, 5xx, битый JSON, гигантский ответ, враждебные заголовки. Проверь, переживёт ли клиент реальную жизнь.

chaos://constructor
